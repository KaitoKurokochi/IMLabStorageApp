# shelves collection

| フィールド    | 型       | 説明                                                                                   |
| ------------- | -------- | -------------------------------------------------------------------------------------- |
| `_id`         | ObjectId | 主キー。MongoDB が自動生成                                                             |
| `label`       | String   | 棚の呼び名(`A-1`、`B-3-2` など)。一意。画面の表示と配置図に使う。URL と QR コードは `_id` を使う |
| `row`         | String   | 段(`A`、`B`、`C`)                                                                      |
| `col`         | Number   | 列(1〜6)                                                                               |
| `description` | String   | 説明(`上段 1列目 (VR・HMD関連)`)                                                       |
